# Photo — page À propos

Déposez ici votre photo avec exactement ce nom de fichier :

- ulrich.jpg

Tant que le fichier est absent, `components/AboutPhoto.js` affiche
automatiquement un placeholder à la place (aucune image externe n'est
chargée).

Format recommandé : portrait, environ 800×1000px (ratio 4:5), .jpg ou .webp,
poids < 300 Ko.

# Images du portfolio

Déposez ici vos captures d'écran avec exactement ces noms de fichiers :

- bibliotheque.jpg
- mini-garage.jpg
- cadellink.jpg
- k2-market.jpg

Tant qu'un fichier est absent, `components/PortfolioCard.js` affiche automatiquement
un placeholder visuel élégant (fond sombre + nom du projet) à la place de l'image —
aucune image externe n'est chargée.

Format recommandé : 1200×900px environ (ratio 4:3), en .jpg ou .webp, poids < 300 Ko.

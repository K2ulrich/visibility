# Image de marque — page d'accueil

Déposez ici votre image avec exactement ce nom de fichier :

- visibility.jpg

Elle s'affiche en format carré dans la section d'accueil (Hero). Tant que le
fichier est absent, un placeholder élégant s'affiche à sa place.

Format recommandé : carré, environ 900×900px, .jpg ou .webp, poids < 300 Ko.

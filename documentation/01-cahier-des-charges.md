# 01 — Cahier des charges

## Contexte

De nombreuses entreprises en Côte d'Ivoire et en Afrique francophone disposent
d'un savoir-faire réel mais restent peu visibles sur Internet, faute d'une
véritable vitrine numérique.

## Problématique

Comment permettre aux PME, entrepreneurs et commerces africains d'obtenir une
présence web professionnelle, accessible et adaptée à leurs moyens ?

## Objectifs

- Présenter clairement l'offre de Visibility (studio de développement web freelance)
- Transformer les visiteurs en prospects
- Servir de vitrine à l'activité freelance d'Ulrich Konan
- Démontrer un savoir-faire technique via le portfolio

## Cible

PME, TPE, entrepreneurs, startups, commerces, associations, professionnels
indépendants, restaurants, artisans, entreprises agroalimentaires et de
services — prioritairement en Côte d'Ivoire / Afrique francophone, avec une
ouverture possible à une clientèle internationale.

## Fonctionnalités

- Pages : Accueil, Réalisations, Services & Tarifs, À propos, Contact
- Formulaire de contact fonctionnel (EmailJS, sans backend)
- Bouton WhatsApp accessible sur toutes les pages
- Portfolio de 4 projets avec descriptions et technologies
- Grille de tarifs indicatifs pour 3 offres + maintenance sur devis
- Navigation responsive avec menu mobile
- SEO de base (title, meta description, Open Graph, sitemap, robots.txt)

## Contraintes

- Pas de backend ni de base de données pour cette version
- Aucune image externe téléchargée : placeholders propres en attendant les
  visuels définitifs
- Ne pas exagérer l'expérience professionnelle d'Ulrich Konan (étudiant /
  développeur en formation, pas un expert senior)
- Prix affichés comme indicatifs uniquement

## Technologies

Next.js, React, Tailwind CSS, Framer Motion, EmailJS. Hébergement prévu sur
Vercel, code géré via Git/GitHub.

## Livrables

- Code source complet du site (projet Next.js)
- Documentation complète (ce dossier)
- Fichiers de configuration (.env.example, .gitignore)

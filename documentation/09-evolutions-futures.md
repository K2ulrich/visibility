# 09 — Évolutions futures

Pistes d'évolution pour les versions suivantes du projet, au-delà de ce
premier site vitrine :

- **CMS** : brancher un CMS headless (Sanity, Strapi, Contentful...) pour
  gérer le portfolio et les tarifs sans toucher au code.
- **Espace client** : zone privée permettant à chaque client de suivre
  l'avancement de son projet.
- **Dashboard** : tableau de bord interne pour suivre les demandes reçues
  via le formulaire de contact.
- **Authentification** : comptes utilisateurs pour l'espace client.
- **Gestion des sites clients** : si Visibility héberge plusieurs sites
  clients, un système de gestion centralisé.
- **Base de données** : stockage des demandes de contact et des projets
  au-delà d'un simple envoi d'email.
- **Paiement en ligne** : intégration d'une solution de paiement (Wave,
  Orange Money, Stripe...) pour les offres e-commerce.
- **Système d'abonnement** : offres de maintenance récurrente facturées
  automatiquement.
- **Analytics** : suivi de fréquentation (Plausible, Vercel Analytics ou
  équivalent respectueux de la vie privée).
- **Génération de sites** : outil interne permettant de dupliquer
  rapidement ce template pour de futurs clients.
- **Multi-tenant** : une seule base de code servant plusieurs sites
  clients avec des données séparées.
- **Gestion automatisée des domaines** : automatiser l'achat et la
  configuration DNS des domaines clients.

Ces évolutions ne sont pas nécessaires pour la première version du site et
devront être évaluées selon les besoins réels une fois Visibility lancé.
